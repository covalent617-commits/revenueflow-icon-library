# RevenueFlow Visual Asset Governance

## Authority
This repository is the authoritative reference for RevenueFlow icons, motion, loading states, illustration concepts and design tokens. It is a shared design source, not a runtime dependency or proof that an asset has been integrated into the product.

## Mandatory rules
1. Search `assets/manifest.json` by stable ID, semantic name, keywords and category before creating or importing any visual asset.
2. Use only entries marked `approved` in production. `proposed` and `experimental` entries require explicit design/product approval; never use `deprecated` entries in new work.
3. Use the manifest's standalone SVG `source` path or the matching `rf-<symbol>` in `assets/icons.svg`. Preserve the stable asset ID in implementation notes.
4. Do not add runtime dependencies on remote icon CDNs. Never silently substitute emoji, arbitrary Unicode glyphs, random SVGs, unrelated icon packs, stock illustrations or unreviewed animations.
5. Preserve semantic meaning, accessible names, focus behaviour, contrast and responsive sizing. Decorative icons must be hidden from assistive technology; icon-only controls need an accessible name on the control.
6. Respect `prefers-reduced-motion`. Motion must communicate a real state, never decorative noise or false activity.
7. If no approved asset fits, report the gap with intended meaning, proposed name/ID, variants and accessibility needs. Do not choose a random substitute.
8. Update the manifest, canonical SVG sprite (for icons), generated files, previews, documentation and tests together.
9. Do not mark an asset approved merely because an SVG exists. Approval is an explicit design/product decision.
10. Report reference availability, code integration, tests and browser verification as separate facts.

## Canonical source map
- Metadata and approval state: `assets/manifest.json`
- Icon geometry: `assets/icons.svg`
- Standalone SVGs and website catalogue data: generated by `scripts/build_assets.py`
- Design tokens: `tokens/design-tokens.json`
- Motion rules: `docs/MOTION-SPEC.md` and `assets/motion.css`

## Validation
```bash
python scripts/build_assets.py
python scripts/validate_assets.py
```
